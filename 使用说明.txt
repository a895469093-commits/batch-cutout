======================================
 批量抠图 使用说明
======================================

【这是什么】
GPT-Image-2 批量去背景网页。拖图上传,出透明PNG,
可打包下载。带 Cloudflare 外网隧道,同事在外网也能用。

【怎么用】
1. 确认 Clash 在运行(端口7897),但 TUN模式/系统代理 要关闭
   —— 隧道需要直连,调GPT的API会自动走Clash,两不耽误
2. 双击「一键启动.bat」
3. 窗口里出现 https://xxx.trycloudflare.com
   这个就是公网地址,发给同事即可
4. 不需要外网时,也可以只开服务,局域网访问:
   http://本机IP:8400  (需先运行一次 开启远程访问.bat 放行防火墙)

【停止】
双击「停止服务.bat」,或直接关掉启动窗口。

【注意事项】
- 外网地址每次重启会变,重启后把新地址重新发给同事
- 电脑关机/睡眠服务就停了;长期使用建议部署到服务器
- API Key 在 .env 文件里,不要发给任何人
- 单张约60~90秒,费用约 $0.0085/张

【首次准备(只需一次)】
- 安装依赖: pip install -r requirements.txt
- 复制 .env.example 为 .env,填入 APIMART_API_KEY
- 隧道工具在 C:\tools\cloudflared.exe(已装好)
