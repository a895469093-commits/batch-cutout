======================================
 批量抠图 便携版 使用说明
======================================

【这是什么】
GPT-Image-2 批量去背景网页。拖图上传,出透明PNG,
可打包下载。自带外网隧道,同事在任何网络都能访问。

【拿到新电脑怎么用】
1. 把整个文件夹拷过去(不用拷 .venv 和 data,会更小)
2. 电脑需要装好 Python 3.10+(没装会提示下载地址)
3. 双击「一键启动.bat」
   首次运行自动:创建环境 → 装依赖(清华镜像) → 下载隧道工具 → 让你粘贴API Key
   之后每次双击直接秒开
4. 窗口出现 https://xxx.trycloudflare.com 就是公网地址,发给同事
5. 停止:双击「停止服务.bat」或直接关窗口

【关于代理(重要)】
- 调 GPT 的接口要不要走代理,首次配置时会问你,存进 .env
  以后要改,直接编辑 .env 里的 PROXY_FOR_API
- 隧道需要直连。如果隧道一直连不上,把这电脑代理软件的
  "TUN模式/虚拟网卡"关掉再启动;或给代理加直连规则:
  DOMAIN-SUFFIX,argotunnel.com,DIRECT

【注意事项】
- 外网地址每次重启会变,重启后把新地址重新发给同事
- 电脑关机/睡眠服务就停
- API Key 在 .env 文件里,不要发给别人
- 单张约60~90秒,约 $0.0085/张
- 费用/密钥管理: https://apimart.ai/keys

【不想装 Python?】
项目也支持 Docker: docker compose up -d(有 Docker 的机器)
